# NFC Карты

Нажми CONNECT → приложи карту к задней панели у камеры → приложение считает UID и содержимое.
Карты сохраняются в историю, у каждой есть журнал проходов.

## Сборка
1. Android Studio → Open → эта папка
2. Build → Build APK(s)
3. app/build/outputs/apk/debug/app-debug.apk

Или: ./gradlew assembleDebug
