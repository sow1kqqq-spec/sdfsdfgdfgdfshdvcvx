# NFC Карты

1. Читать карту - CONNECT, приложить карту к задней панели у камеры.
2. Быть картой - "МОЯ", включить эмуляцию, второй телефон читает этот как пропуск.

## Сборка
Android Studio -> Open -> Build -> Build APK(s)
Файл: app/build/outputs/apk/debug/app-debug.apk
Нужен Gradle JDK 17 (Settings -> Build Tools -> Gradle).
